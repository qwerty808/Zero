# Habit & Task Tracker Telegram Bot (Python)

Телеграм‑бот для трекинга **привычек** и **задач** с хранением в **SQLite** и ежедневными **напоминаниями**.

## Возможности

- **Привычки**: добавить, посмотреть список, отметить “сделано сегодня”, удалить (деактивировать)
- **Задачи**: добавить, посмотреть список, закрыть, удалить
- **Напоминания**: ежедневно в заданное время (**UTC**)
- **Инлайн‑кнопки**: “✅ Сделано/Готово” прямо в списке

## Быстрый старт

1) Создай бота у `@BotFather` и получи токен.

2) Установи зависимости:

```bash
python -m pip install -r requirements.txt
```

3) Создай `.env` (можно скопировать из примера):

```bash
cp .env.example .env
```

Впиши в `.env`:

- `BOT_TOKEN` — токен бота
- `DB_PATH` — путь к sqlite базе (по умолчанию `data.db`)

4) Запусти:

```bash
python bot.py
```

## Команды

Привычки:

- `/addhabit <название>` — добавить привычку
- `/habits` — список привычек (с кнопками “✅ Сделано”)
- `/habitdone <id>` — отметить привычку выполненной сегодня
- `/delhabit <id>` — удалить (деактивировать) привычку

Задачи:

- `/addtask <текст>` — добавить задачу
- `/tasks` — список задач (с кнопками “✅ Готово”)
- `/taskdone <id>` — закрыть задачу
- `/deltask <id>` — удалить задачу

Напоминания (время **UTC**):

- `/setreminder HH:MM` — ежедневное напоминание
- `/reminderoff` — выключить напоминания

Дополнительно:

- `/summary` — короткая сводка (что осталось на сегодня)
- `/help` — помощь
