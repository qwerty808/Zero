# Zero — Habit/Task Tracker Telegram Bot (Python)

Телеграм‑бот для трекинга **задач** и **привычек**, которые теперь объединены в одну сущность: **Item**.

- **Task** = `Item(kind=task, recurrence=once)` — закрывается один раз
- **Habit** = `Item(kind=habit, recurrence=daily)` — повторяется по периодам

Данные хранятся в **SQLite**. При старте выполняется **миграция** со старых таблиц `habits/tasks` в новые `items/item_logs`.

## Возможности

- **Items**: добавить, смотреть списки (всё/задачи/привычки), отметить “✅” (для текущего периода), удалить
- **Напоминания**: **на уровне каждого Item** (`/remind id HH:MM`) — бот шлёт список items, которые “ещё надо” для этого времени (**UTC**)
- **Статистика**: краткая и подробная (тренд 7 дней)
- **Меню кнопками** + быстрый ввод (нажал кнопку → отправил одним сообщением)

## Быстрый старт

1) Создай бота у `@BotFather` и получи токен.

2) Установи зависимости:

```bash
python -m pip install -r requirements.txt
```

3) Создай `.env` (можно скопировать из примера):

```bash
cp .env.example .env
```

Впиши в `.env`:

- `BOT_TOKEN` — токен бота
- `DB_PATH` — путь к sqlite базе (по умолчанию `data.db`)

4) Запусти:

```bash
python bot.py
```

## Команды

Меню:

- `/menu` — показать кнопки (быстро добавить/посмотреть/статистика)

Items (унифицировано):

- `/items` — все активные items
- `/tasks` — активные задачи
- `/habits` — активные привычки
- `/done <id>` — отметить выполненным (для текущего периода)
- `/del <id>` — удалить (деактивировать)

Быстрое создание (совместимость):

- `/addtask «текст»` — создать task (once)
- `/addhabit «название»` — создать habit (daily)

Напоминания (время **UTC**, на уровне item):

- `/remind <id> HH:MM` — включить напоминание для item
- `/remindoff <id>` — выключить напоминание для item

Дополнительно:

- `/summary` — короткая сводка (что осталось на сегодня)
- `/stats` — подробная статистика (унифицированная + тренд за 7 дней)
- `/stats_short` — краткая статистика
- `/help` — помощь

## Меню (кнопки)

После `/start` или `/menu` появится нижнее меню:

- **➕ Задача** — бот попросит текст задачи (одним сообщением)
- **➕ Привычка** — бот попросит название привычки
- **📋 Задачи / 🔥 Привычки / 📋 Всё** — открыть списки (с инлайн‑кнопками ✅)
- **📌 Сводка** — что осталось на сегодня
- **📊 Статистика / 📊 Кратко** — подробная и краткая статистика
- **❌ Отмена** — отменить ввод, если бот ждёт текст
